# KVB Tram Station API
This learning project is a FastAPI that looks for upcoming trams on Station X.
It is a very simple API wrapped around a scraper I build utilising the BeautifulSoup parser as I ran into issues using Regex.

The API is „compact“ as it owns no own data and every request is handled by the KVB website.
It handles pretty much error and serves the departure data as a JSON.
